Замер нативный, release, 100 000 узлов. WASM ожидается в 1.5–2 раза медленнее.

Запуск: `cargo run --release -p ferrum-editor --example editor_report`.

Как читать таблицу:
- Цели проверяются по медианам; худшие значения (строки «То же, худшее…») справочные, без цели.
- Перетаскивание 1000 выделенных — дети первых фреймов верхнего ряда; привязки ищутся запросами к R-tree по видимой части.
- Запись и отмена — медиана пяти повторов: отпускание (одна транзакция в 1000 правок и обновление сцены) и `Undo`.
- Наведение при 1000 выделенных: стоимость растёт вместе с выделением (~0.11 мс против 0.001 мс без него), цель та же — 0.2 мс.
- Перетаскивание фрейма при отдалении: соседи — тысяча фреймов верхнего уровня, полоса привязки в мире шире в 1/зум раз; на зуме 0.03 вся страница в кадре.
